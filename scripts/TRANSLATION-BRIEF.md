# Vito — add the missing UI strings to one language file

Vito is a voice-dictation app: you press a hotkey, speak, and the transcribed
text is pasted where your cursor is. The UI has a status page with usage
statistics and a cost estimate, a settings page, a dictionary and a history.

## Your job

Add every key from `scripts/missing-keys.json` to `web/i18n/<CODE>.json`,
translated into your assigned language. (That file is generated by
`pwsh -File scripts/i18n-missing.ps1 -Export`; it already exists when you are
briefed.)

The file is JSON with two objects: `strings` (key → translation) and `help`.
**Add the new keys to `strings` only. Do not touch, reorder or reformat any
existing entry, and do not touch `help`.** Read the file, insert the new pairs,
write it back as UTF-8 without BOM, keeping the existing indentation style.

## The keys

`scripts/missing-keys.json` lists the English source strings your language is
missing. Each key is what the code looks up — copy it verbatim — and is also the
text to translate. Translate the meaning into your language; don't render it
word by word.

## Rules that matter

- **Keep placeholders and symbols exactly**: `{n}`, `→`, `≈`, amounts, `ms`.
- `"EN, ES, FR, DE, IT, PT"` is a list of language codes — leave it unchanged.
- `"hr"` is the unit in a price like `$0.45/hr` — use your language's short
  form for "hour" (de: `Std.`, fr: `h`, es: `h`, ja: `時間`).
- `"Keyterms +$0.04/hr"`: keep the amount, translate the rest. "Keyterms" is
  Vito's term for words you feed the recogniser; keep it if your language has
  no established equivalent.
- `"(Voice In, Text Out)"` and `"(Bring your own key)"` are glosses printed
  after the English product terms they gloss. Translate the meaning into your
  language and keep the parentheses; they are hidden when the UI is English.
- Long strings are tooltips or help texts explaining a statistic or a setting.
  Keep them natural and complete; don't shorten them into labels.
- Use the register the rest of the file already uses (informal "you" where the
  existing entries do).
- No trailing whitespace, no smart-quote substitutions inside JSON values.

## When done

Verify the file still parses as JSON and report: the language code, how many
keys you added, and anything you deliberately left in English (with the reason).
